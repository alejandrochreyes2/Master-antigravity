# Master Antigravity Proyectos

Bienvenido al repositorio principal de proyectos del máster. Cada proyecto se encuentra alojado en su propia rama (*branch*) para mantener el historial limpio y organizado.

## 📋 Lista de Proyectos

A continuación se listan los proyectos disponibles:

1. [**01-tareas-pendientes**](https://github.com/alejandrochreyes2/Master-antigravity/tree/01-tareas-pendientes)
   - Aplicación de gestión de tareas estilo *ZenTasks*.
   - Construida con Angular 21, Signals y TailwindCSS.
   - Incluye persistencia local y soporte para modo oscuro.

2. [**02-generador-contraseñas**](https://github.com/alejandrochreyes2/Master-antigravity/tree/02-generador-contrasenas)
   - Utilidad web generadora de contraseñas seguras y aleatorias con copia automática.
   - Construida exclusivamente con HTML5, CSS3 y JavaScript Vanilla.
   - Interfaz moderna, minimalista y responsiva, siguiendo el estándar de 1rem = 10px.

*Nota: Para ver el código de un proyecto, haz clic en el enlace para navegar a su rama correspondiente.*
